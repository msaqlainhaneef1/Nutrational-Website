Taco Bell Nutrition Calculator

A Taco Bell order can change substantially before it reaches the bag.

You can start with a Crunchy Taco, Crunchwrap Supreme, burrito, quesadilla, Cantina Chicken item, Nacho Fries, or another recipe, then change the protein, remove cheese, make it Fresco, add potatoes, add rice, add beans, change sauces, add guacamole, or turn several individual foods into a combo.

That makes Taco Bell especially well suited to a recipe-based nutrition calculator .

Use the Taco Bell Nutrition Calculator above to start with the standard menu item, then make the same changes you made when ordering.

Start With the Standard Taco Bell Recipe

For a named Taco Bell item, use the restaurant's standard recipe as the starting point.

Taco Bell has long offered a Fresco customization system that replaces dairy and mayo-based sauces with freshly prepared tomato or pico-style ingredients where supported.
